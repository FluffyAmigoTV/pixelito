Welcome to Pixelito

A quick tour. Everything here is also in the menus, and Ctrl+K finds any command by name.

  1. Draw with the tools on the left. Hover a tool to see its key, like B for pencil. Right-click erases. Alt-click picks a color.
  2. Pick colors on the right. The two swatches are your drawing and background colors, X swaps them. Ramp… makes a set of shades.
  3. Move around with the mouse wheel to zoom. Move the board by dragging the empty space around it, with the Hand tool (H), or Space plus drag. On a touch screen, pinch and drag with two fingers.
  4. Animate with Add frame below the canvas. Shift-click frames to select several, then New tag names them, like walk or attack. Enter plays.
  5. Select with Select, Lasso or Wand. Ctrl+T moves, scales or rotates the selection; Enter places it.
  6. Keep your work with Save (Ctrl+S). The editor also autosaves as you go and keeps a backup every minute (Open project lists them).
  7. Send it to Unity with Export: a sprite sheet and JSON, a tileset, a GIF, or single PNGs, saved in the exports folder.

Install Pixelito as an app

  1. iPad and iPhone: open this page in Safari, tap the Share button, then Add to Home Screen.
  2. Android: open it in Chrome, tap the ⋮ menu, then Install app (or Add to Home screen).
  3. Windows: use the Pixelito installer, or in Edge or Chrome choose Install Pixelito from the menu.

Installed, it opens full screen and works without internet. Your projects stay on that device; use File > Save a copy as a file to move one to another device.

    Shade ramp

    Makes a row of shades from the drawing color, dark to light. Hue shifting turns shadows cooler and highlights warmer, the way pixel artists usually shade.

    Export palette

    On a PC it goes in the exports folder; on a tablet it downloads. GIMP .gpl works in Aseprite, GIMP and Krita; .pal is JASC (Paint Shop Pro, many tools); .hex is one color per line (Lospec).

    Export

    A sprite sheet PNG plus a JSON file with each frame's position, duration and tags (the same layout Aseprite uses). On a PC they go in the exports folder; on a tablet they download, several files together as one .zip.
